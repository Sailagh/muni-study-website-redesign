# Study Website Redesign – Bi1060c (MUNI)

## Why this project exists
This project was created as a school assignment.
A friend used the original website as study material for a mandatory university class at MUNI
and found it difficult to navigate and confusing to use.

The goal of this project was to redesign the website to make it clearer,
easier to navigate, and more pleasant to use while keeping the original educational purpose.

## What was improved
- clearer navigation structure
- improved layout and visual hierarchy
- better readability of study materials
- more modern and student-friendly design

## Technologies used
- HTML
- CSS
- JavaScript

## Original website
https://www.sci.muni.cz/~anatomy/1_page/1_page.htm

## Note on assets
For portfolio purposes, only a representative subset of images is included in this repository.
The full image set was reduced to keep the repository lightweight while preserving the structure
and visual presentation of the website.
